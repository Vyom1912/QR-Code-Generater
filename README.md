# 🔳 QR Code Generator

Turn any text, URL, e-mail, phone number and more into a QR code instantly, using the free [QR Server API](https://goqr.me/api/).

## ✨ Features

- Generate a QR code from any text or URL
- QR code preview appears with a smooth animation
- Input shake/error effect when the field is empty
- Download buttons for **PNG** and **JPG**

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla, Canvas API)
- [QR Server API](https://goqr.me/api/)
- [Font Awesome](https://fontawesome.com/)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vyom1912/<repository-name>.git
   ```
2. Open `index.html` in your browser — no build step or installation needed.

> Tip: For the best experience, use the **Live Server** extension in VS Code.
